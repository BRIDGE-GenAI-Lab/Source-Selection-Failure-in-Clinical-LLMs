**Figure 4 | Position-averaged accuracy by model in the original evaluations of the non-identical pairs.** Bars: position-averaged accuracy, the mean of the accuracy with the modified excerpt shown first and with it shown second; whiskers: 95% CI. Circles: accuracy with the modified excerpt first; diamonds: accuracy with the modified excerpt second. Each model saw each pair once, in one order; within a model, the two come from different pairs. Bar color: reasoning model, closed commercial model or open-weight model. Models are ordered by position-averaged accuracy; the dashed line marks 50% (chance). Each model: 333 evaluations, one per pair. Analysis set: the original evaluations of the 333 pairs whose authentic and modified excerpts differ in content visible to the models (n = 6,993 evaluations, 21 models, one evaluation per model and pair). Excluded: the 167 pairs whose two excerpts were identical as presented (3,507 evaluations). The 413 evaluations of this set whose choice the original runner set to A are included (a sensitivity analysis excludes them). 95% CIs: case-cluster bootstrap over vignettes (2,000 resamples).
