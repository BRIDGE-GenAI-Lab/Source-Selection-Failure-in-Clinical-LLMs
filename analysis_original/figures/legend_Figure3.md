**Figure 3 | Failure rate by modification type in the original evaluations of the discriminable pairs.** A failure is a selection of the modified excerpt. Bars: failure rate pooled across the 21 models, colored by modification category; whiskers: 95% CI; n: evaluations of each type. The dashed line marks 50%, the rate expected from a choice made by chance. †Fabricated citation (hatched) is cue-confounded: in all 840 of its evaluations the modified excerpt carried the DOI 10.9999/fake.NNNN, so the word "fake" was visible, and in all 840 it had a blank line before the citation that no authentic excerpt had. Contraindication violation and missing warning are not shown: none of their pairs differed in content visible to the models. Differences between types are associations: modification type is confounded with vignette, clinical task and guideline. Analysis set: the original evaluations of the 333 pairs whose authentic and modified excerpts differ in content visible to the models (n = 6,993 evaluations, 21 models, one evaluation per model and pair). Excluded: the 167 pairs whose two excerpts were identical as presented (3,507 evaluations). The 413 evaluations of this set whose choice the original runner set to A are included (a sensitivity analysis excludes them). 95% CIs: case-cluster bootstrap over vignettes (2,000 resamples).
