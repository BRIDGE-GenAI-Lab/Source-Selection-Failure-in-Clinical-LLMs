**Figure 2 | Position effects in the original evaluations of the non-identical pairs.** a, Share of selections of the excerpt in the first position (A), pooled across the 21 models and for each runner configuration (bars; whiskers, 95% CI); points, individual models. b, Accuracy with the modified excerpt shown first (A) and second (B), pooled and for each configuration (bars; whiskers, 95% CI); Figure 4 gives them for each model. Configurations: 1, OpenAI, function calling (4 models); 2, Gemini, excerpts inline (1 model); 3, DeepSeek-Chat, excerpts inline (1 model); 4, DeepSeek-Reasoner, excerpts inline (1 model); 5, Together AI, excerpts inline (14 models). The dashed lines mark 50%, the value expected without a position preference (a) and without discrimination (b). Each model saw each pair once, in one order; within a model, the two accuracies in b therefore come from different pairs. Analysis set: the original evaluations of the 333 pairs whose authentic and modified excerpts differ in content visible to the models (n = 6,993 evaluations, 21 models, one evaluation per model and pair). Excluded: the 167 pairs whose two excerpts were identical as presented (3,507 evaluations). The 413 evaluations of this set whose choice the original runner set to A are included (a sensitivity analysis excludes them). 95% CIs: case-cluster bootstrap over vignettes (2,000 resamples).
