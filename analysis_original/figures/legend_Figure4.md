**Figure 4 | Position-averaged accuracy by model in the original evaluations of the non-identical pairs.** Bars: position-averaged accuracy, the mean of the accuracy with the modified excerpt shown first and with it shown second; whiskers: 95% CI. Circles: accuracy with the modified excerpt first; diamonds: accuracy with the modified excerpt second. Open squares: position-averaged accuracy among only the evaluations with a valid A or B reply, for the 12 models whose choice the original runner set to A in some evaluations; the label gives each one's valid replies (Supplementary Table S9, Part D). For Qwen3-Next-80B, these were 168 of its 333 evaluations. The squares are conditional on a valid reply, a selected subset rather than a random sample; they are not the models' overall accuracy and do not rank the models. Each model saw each pair once, in one order; within a model, the two accuracies (circle and diamond) come from different pairs. Bar color: reasoning model (including GPT-5-Nano, a closed commercial reasoning model), other closed commercial model or open-weight model. Models are ordered by position-averaged accuracy; the dashed line marks 50% (chance). Each model: 333 evaluations, one per pair. Analysis set: the original evaluations of the 333 pairs whose authentic and modified excerpts differ in content visible to the models (n = 6,993 evaluations, 21 models, one evaluation per model and pair). Excluded: the 167 pairs whose two excerpts were identical as presented (3,507 evaluations). The 413 evaluations of this set whose choice the original runner set to A are included (a sensitivity analysis excludes them). 95% CIs: case-cluster bootstrap over vignettes (2,000 resamples).
